# Student Grade Management System

A Java-based console application for storing and managing student names and marks. The application validates user input, handles invalid entries using exception handling, calculates average, highest, and lowest marks, and generates a clear, formatted summary report.

## Features

* Store student names and marks using ArrayLists
* Validate the number of students
* Validate student names
* Accept marks between 0 and 100
* Handle invalid numeric input using InputMismatchException
* Calculate average marks
* Find the highest marks
* Find the lowest marks
* Display a formatted student grade report

## Technologies Used

* Java


## How It Works

1. Enter the number of students.
2. Enter each student's name.
3. Enter the marks for each student.
4. The application validates the entered data.
5. A formatted report displays each student's marks.
6. The application calculates and displays the average, highest, and lowest marks.
